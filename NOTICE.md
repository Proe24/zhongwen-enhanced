## Changes made in this fork

Per GPL v2 §2(a), the following are the principal modifications to the
original work, with the year of change:

- **2026** — Added AI-powered sentence breakdown. Selected Chinese text
  can be sent to a user-chosen AI provider (Anthropic Claude, Google
  Gemini, or OpenAI) using the user's own API key, returning a
  word-by-word grammatical breakdown.
- **2026** — Added named vocabulary lists, sentence storage, and flashcard
  study features.
- **2026** — Added export to Anki and Pleco formats.
- **2026** — Migrated the extension from Manifest V2 to Manifest V3
  (service worker background script).
- **2026** — Redesigned the pop-up and word-list UI, added theming,
  fonts, and a configurable pop-up size.
- **2026** — Added an offline character-detail view (press **E**) showing
  stroke-order animation, component decomposition, the radical, and
  etymology, powered by bundled open data (see below).
- **2026** — Added an offline thesaurus (press **L**) showing synonyms,
  with a link-out fallback for words not in the offline data.

## Bundled third-party components

This extension bundles the following independently-licensed components,
whose own licenses apply to those files:

- **jQuery** (`js/jquery-3.7.1.min.js`) — JavaScript library by the
  jQuery Foundation and contributors. MIT License.
  <https://jquery.org/license/>
- **Bootstrap** (`css/bootstrap.min.css`, `js/bootstrap.min.js`) — CSS/JS
  UI toolkit by The Bootstrap Authors. MIT License.
  <https://github.com/twbs/bootstrap/blob/main/LICENSE>
- **Hanzi Writer** (`js/hanzi-writer.min.js`) — stroke-order rendering
  library by Jason Kennaly and contributors. MIT License.
  <https://hanziwriter.org/>
- **Character data** (`data/chardata/`) — generated by
  `tools/build-chardata.js` from:
  - *hanzi-writer-data* (MIT) — stroke paths and medians.
  - *Make Me a Hanzi* (LGPL-3.0; stroke graphics derived from Arphic PL
    fonts under the Arphic Public License) — decomposition, radical, and
    etymology. <https://github.com/skishore/makemeahanzi>
- **CC-CEDICT** (`data/cedict_ts.u8`) — Chinese-English dictionary data,
  CC BY-SA 4.0. <https://www.mdbg.net/chinese/dictionary?page=cedict>
- **Thesaurus data** (`data/thesaurus.json`) — generated by
  `tools/build-thesaurus.js` from the *Chinese Open Wordnet* (COW) by
  Shan Wang and Francis Bond, CC BY 3.0.
  <https://bond-lab.github.io/cow/>
